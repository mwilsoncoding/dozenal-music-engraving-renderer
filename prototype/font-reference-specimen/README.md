# Prototype: Font Reference Specimen

Open `index.html` in a browser. The bottom switcher compares Bravura, Petaluma, and Leland; the selected variant is shareable with `?variant=bravura`, `?variant=petaluma`, or `?variant=leland`. Left/right arrow keys also switch candidates.

This is a disposable visual specimen, not production rendering. Font text and the bundled font binaries are references only; the production output remains independently drawn SVG paths. The page includes the DejaVu Sans Bold 700 reference, custom dek/el sketches, SMuFL time-signature digits, rests, and note flags.

Pinned assets and upstream license notices are in `assets/fonts/`:

- DejaVu Sans 2.37 Bold: `DejaVuSans-Bold.ttf`, with `DejaVu-LICENSE`.
- Bravura 1.482: `Bravura.otf`, with `Bravura-OFL.txt`.
- Petaluma 1.065: `Petaluma.otf`, with `Petaluma-OFL.txt`.
- Leland 0.80: `Leland.otf`, with `Leland-LICENSE.txt`.
